# Cynaris Career Intelligence: Enterprise Skills Taxonomy Document
Version: 1.0 | 50 Skills Across 5 Core Full Stack & AI Domains

---

## Domain 1: Frontend Development
1. **HTML5 Semantic Structure** (Critical): Semantic elements (`<main>`, `<article>`, `<section>`), ARIA accessibility, SEO optimization, and form validation.
2. **CSS3 & Modern Layouts** (Critical): Flexbox, CSS Grid layouts, responsive viewports, keyframe animations, and media queries.
3. **JavaScript ES6+** (Critical): Asynchronous programming (`async/await`, Promises), closures, prototypal inheritance, destructuring, and ES modules.
4. **React.js Component Architecture** (Critical): Functional components, React Hooks (`useState`, `useEffect`, `useMemo`), component lifecycle, and virtual DOM reconciliation.
5. **Tailwind CSS** (Important): Utility-first styling, JIT compiler, responsive modifiers, and design token integration.
6. **TypeScript Typing & Interfaces** (Important): Static typing, generics, utility types, interfaces, and compiler configurations.
7. **Chart.js Data Visualization** (Important): Canvas rendering, radar charts for skill mapping, line charts, and dynamic dataset updating.
8. **Next.js SSR & SSG** (Nice-to-have): Server-side rendering, static site generation, API routes, and hydration optimization.
9. **Redux Toolkit & State Management** (Nice-to-have): Global predictable state container, slices, thunk middleware, and selectors.
10. **Web Performance Optimization** (Important): Core Web Vitals, code splitting, lazy loading, Lighthouse scoring, and bundle size reduction.

---

## Domain 2: Backend Development
11. **PHP 8.x Modern Features** (Critical): Typed properties, union types, match expressions, attributes, nullsafe operators, and JIT compilation.
12. **Laravel Framework Architecture** (Critical): Service providers, dependency injection container, Eloquent ORM, Blade templating, and artisan CLI.
13. **RESTful API Design & Contracts** (Critical): HTTP methods, standard status codes (200, 422, 500), RFC-compliant JSON responses, and versioned routes.
14. **MVC & Clean Code Patterns** (Critical): Separation of concerns, thin controllers, fat domain services, and SOLID principles.
15. **Python Fast Execution & AsyncIO** (Important): Asynchronous event loop, coroutines, generators, and typing.
16. **FastAPI Web Framework** (Important): High-speed ASGI framework, Pydantic data schemas, automatic OpenAPI documentation, and dependency injection.
17. **Authentication & Authorization** (Critical): JWT tokens, bearer authentication, role-based access control (RBAC), and session security.
18. **Microservices Communication Patterns** (Important): API gateways, message queues, event-driven architecture, and Saga pattern transactions.
19. **gRPC & Protocol Buffers** (Nice-to-have): Compact binary serialization, HTTP/2 streaming, and cross-language remote procedure calls.
20. **Asynchronous Queue Workers** (Critical): Background job processing, Redis queue backends, retry policies, and dead-letter queues.

## Domain 3: Databases & Storage
21. **Relational Modeling & Normalization (3NF)** (Critical): Entity-Relationship design, 1NF, 2NF, 3NF normalization, and referential integrity.
22. **MySQL & MariaDB Query Execution** (Critical): Multi-table JOINs, nested subqueries, grouping aggregations, and ACID transaction boundaries.
23. **EXPLAIN Query Performance Profiling** (Critical): Analyzing execution plans, index scans vs table scans, and composite covering indexes.
24. **Redis In-Memory Caching** (Critical): In-memory key-value stores, hash maps, TTL expiry, rate limiting counters, and pub/sub.
25. **ChromaDB Vector Embeddings Store** (Important): Vector collections, dense cosine similarity search, metadata filtering, and semantic candidate indexing.
26. **PostgreSQL & pgvector Extension** (Important): Storing vector embeddings directly within relational tables, HNSW indexing, and hybrid queries.
27. **Database Indexing Strategies** (Critical): B-Tree indexes, composite keys, prefix indexing, and cardinality optimization.
28. **MongoDB Document NoSQL Modeling** (Nice-to-have): JSON/BSON document collections, aggregation pipelines, and embedded vs normalized modeling.
29. **Database Migrations & Seeding** (Critical): Version-controlled database schema evolution, rollbacks, and reproducible test fixtures.
30. **Connection Pooling & Replication** (Nice-to-have): Read replicas, write master failover, connection reuse, and connection timeout management.

## Domain 4: DevOps & Cloud Infrastructure
31. **Git Advanced Branching & Rebasing** (Critical): Feature branches (`feat/*`), interactive rebasing, merge conflict resolution, and PR templates.
32. **Docker Containerization** (Critical): Multi-stage Dockerfiles, layer caching, slim alpine runtime images, and security best practices.
33. **Docker Compose Orchestration** (Critical): Multi-service topologies, network bridging, persistent named volumes, and service health checks.
34. **CI/CD Automated Pipelines** (Critical): GitHub Actions workflows, automated linting, test runners, and automated release deployment.
35. **Linux Shell Scripting & CLI** (Critical): Bash automation, cron scheduling, system permissions, and environment variable configuration.
36. **Nginx Reverse Proxy & Load Balancing** (Important): Upstream routing, SSL/TLS certificate offloading, gzip compression, and rate limiting.
37. **AWS Architecture (EC2, S3, ALB)** (Important): Compute virtual machines, S3 object storage, Application Load Balancers, and IAM security roles.
38. **Railway & Cloud Container Deployment** (Important): Containerized PaaS hosting, health check endpoints, and automatic redeployment.
39. **Kubernetes Pod & Service Orchestration** (Nice-to-have): K8s pods, deployments, services, ingress controllers, and horizontal autoscalers.
40. **Observability & Centralized Logging** (Important): Structured JSON application logs, error tracing, and performance metrics monitoring.

## Domain 5: AI Systems & LLM Engineering
41. **Prompt Engineering & Few-Shot Design** (Critical): Role assignment, markdown output schemas, few-shot demonstration, and constraint enforcement.
42. **Groq Cloud High-Speed Inference API** (Critical): LPU inference engine, llama-3.3-70b-versatile integration, low-latency completions.
43. **OpenRouter Multi-Model Failover** (Critical): Secondary provider resilience, model fallback cascading, and outage handling.
44. **LlamaIndex Document Ingestion & RAG** (Critical): VectorStoreIndex, Document readers, node chunking, query engines, and response synthesis.
45. **Dense Vector Embeddings Generation** (Critical): `all-MiniLM-L6-v2` 384-dimensional dense vectors, semantic similarity calculations.
46. **ChromaDB Semantic Document Indexing** (Critical): Collection persistence, vector upsert with metadata, candidate namespace partitioning.
47. **RAG Context Window Optimization** (Important): Top-K chunk retrieval, context window packing, chunk overlap, and re-ranking.
48. **LLM Error Handling & Fallback Architectures** (Critical): HTTP 429 rate limit backoff, timeout cascades, and deterministic local knowledge safety nets.
49. **LangChain Chains & Agent Tools** (Nice-to-have): Dynamic tool calling, conversational memory buffers, and multi-step reasoning.
50. **LLM Output Evaluation & Guardrails** (Important): Strict JSON schema validation, boundary checking, and response latency auditing.
